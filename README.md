# Exercícios de Variáveis e Condicionais em Java

Este repositório contém exercícios práticos de **Java** focados em:
- Declaração e manipulação de variáveis
- Estruturas condicionais (`if`, `else if`, `else`)
- Laços de repetição (`for`, `while`, `for-each`)

O objetivo é ajudar no aprendizado dos conceitos básicos de programação e lógica utilizando a linguagem Java.

---

## 📂 Estrutura do Repositório
- `src/` → Contém os arquivos `.java` com os exercícios.
- Cada arquivo representa um exercício independente, com exemplos de uso de variáveis e condicionais.
